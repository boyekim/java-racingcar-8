# java-racingcar-precourse

## 기능 요구 사항

> 초간단 자동차 경주 게임을 구현한다.

- 주어진 횟수 동안 n대의 자동차는 전진 또는 멈출 수 있다.
- 각 자동차에 이름을 부여할 수 있다. 전진하는 자동차를 출력할 때 자동차 이름을 같이 출력한다.
- 자동차 이름은 쉼표(,)를 기준으로 구분하며 이름은 5자 이하만 가능하다.
- 사용자는 몇 번의 이동을 할 것인지를 입력할 수 있어야 한다.
- 전진하는 조건은 0에서 9 사이에서 무작위 값을 구한 후 무작위 값이 4 이상일 경우이다.
- 자동차 경주 게임을 완료한 후 누가 우승했는지를 알려준다. 우승자는 한 명 이상일 수 있다.
- 우승자가 여러 명일 경우 쉼표(,)를 이용하여 구분한다.
- 사용자가 잘못된 값을 입력할 경우 IllegalArgumentException을 발생시킨 후 애플리케이션은 종료되어야 한다.

## 기능 목록

- [x] 경주할 자동차 이름과 시도할 횟수를 입력받는다.
- [x] 입력 받은 횟수 만큼 라운드가 반복 실행된다.
    - [x] 각 라운드 마다 각 자동차의 랜덤 값을 생성한다.
    - [x] 랜덤 값에 기반하여 멈춰있거나 전진한다.
- [x] 전진한 자동차 이름과 함께 라운드 별 자동차 거리를 출력한다.
- [x] 가장 멀리 간 자동차를 판별한다.
- [x] 최종 우승자를 출력한다.

## 예외 목록

- [x] 입력 받은 게임 라운드 수가 빈 값인 경우
- [x] 입력 받은 게임 라운드 수가 음수인 경우
- [x] 입력 받은 게임 라운드 수가 정수 형태가 아닌 경우(소수, char 등)
- [x] 입력 받은 이름이 5자 초과인 경우
- [x] 입력 받은 이름이 중복된 경우
- [x] 입력 받은 이름이 비어있는 경우

## 클래스 설명

### 도메인 객체

| 클래스명         | 역할                                       |
|--------------|------------------------------------------|
| Car          | 자동차의 정보를 관리한다. <br> 자동차의 정보는 이름, 거리가 있다. |
| Cars         | Car들을 관리한다.                              |
| GameCount    | 게임 라운드 수를 정보를 관리한다.                      |
| RacingResult | 라운드 별 결과, 즉 Cars 정보를 관리한다.               |

### 전략 객체

| 클래스명                     | 역할                                                                                      |
|--------------------------|-----------------------------------------------------------------------------------------|
| RandomNumberGenerator    | NumberGenerator를 상속한다. 해당 인터페이스는 숫자를 생성하는 전략을 추상화한 인터페이스이다. <br> 구현체는 랜덤 숫자를 생성한다.      |
| RacingCarForwardStrategy | ForwardStrategy를 상속한다. 전진할 경우를 판별하는 전략을 추상화한 인터페이스이다. <br> 구현체는 랜덤 숫자 생성이 4이상일 경우 전진한다. |
| RacingCarDivider         | DivideStrategy를 상속한다. 입력받은 문자열을 기반으로 자동차를 생성하는 전략을 추상화한 인터페이스이다.<br> 구현체는 구분자로 ,를 사용한다. |
